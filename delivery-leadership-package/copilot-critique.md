Copilot critique (Day 3). I asked Copilot to add two seed quotes. It matched the existing shape exactly, and both rows pass the database schema, so npm run seed accepted all 8. But it also rewrote the provided comment ("six"->"eight") without being asked. And its premiums are invented, though they look historical: they minic the old rate pattern for quotes that never existed, and they're far below what the API charges today. I wouldn't ship them as-is. The sharper point is which gates would catch a bad row. TypeScript wouldn't, because seed.js is JavaScript in the API. CI wouldn't either, because the tests check the routes, not the seed. Only the database schema catches a broken row, and only at runtime. And no gate catches a row that's valid but untrue. AI-drafted data needs a human review.
